# Command Interface

Owns the bounded command parser and JSON serialization boundary for the directly executed Core application.

It exposes `health`, `verify`, non-mutating `paths`, non-launching `browser-doctor`, generic `plugin list|health|invoke`, bounded `auth status|enroll|remove`, and bounded `collection status|submit|worker-once|reconcile|cancel|resume` actions. Plugin invocation accepts one bounded JSON object and reaches only installer-approved `dispatch.plugins` entry points. Collection submission accepts one selected collector ID plus a bounded scalar JSON parameter object and writes only a durable task record; it never runs collection inline. Authentication enrollment reads every credential value through hidden terminal prompts; no command accepts secret values in arguments or returns them in JSON. Collection status is read-only, while submission, worker, cancellation, resume, and reconciliation actions explicitly open private durable state. Feature behavior remains in the owning Core packages.
